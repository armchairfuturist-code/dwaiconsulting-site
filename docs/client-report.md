# DWAI Consulting — New Website Summary

A plain-English overview of what the rebuilt website does that the old one could not.

---

## 1. Hosting — moved from GoDaddy to Cloudflare

| Old (GoDaddy) | New (Cloudflare) |
|---|---|
| ~ **$600 / year** for hosting | **Free** — charges only if traffic spikes beyond free tier |
| Managed entirely by GoDaddy | You own every credential — no vendor lock-in |
| Hard to change anything | Push code changes from this laptop in seconds |
| Pages rendered through their builder | Pages are fast HTML served from the edge |

Your domain stays registered with GoDaddy — nothing is lost. Only hosting moves.

## 2. Speed — page loads three times faster

I measured both sites on a realistic mobile connection:

| Metric | Old site | New site | Improvement |
|---|---|---|---|
| HTML downloaded | 136 kB | 33 kB | **2× less data** |
| Time to first byte (TTFB) | 241 ms | 115 ms | **2× faster** |
| Total time to visible content | 330 ms | 116 ms | **~3× faster** |

The new site starts showing text before half of it has downloaded.

## 3. Contact form — leads go straight to you

The GoDaddy site had a contact form embedded on 9 out of 11 pages. I rebuilt it exactly, then improved it:

- **Same fields**: Name, email, phone, company, employee count (range), renewal month, notes.
- **Intake checklist**: A downloadable CSV template lives next to the form so clients can prepare their employee census data beforehand. The results arrive to you with complete information rather than incomplete guesses.
- **Spam protection**: Hidden honeypot field prevents automated submissions while real visitors never notice it.
- **Validation happens before sending**: Invalid emails, missing name, or skipped required fields get highlighted inline with clear messages — no waiting for a "page not found" error after submission.
- **Delivery to your inbox**: Every submission arrives at `steve@dwaiconsulting.com` with subject line including the company name, employee range, and renewal month — you can see who to prioritize before opening.
- **Fallback safety**: If the delivery service is temporarily unreachable, the form tells the visitor to email or call instead rather than silently swallowing the lead.

The form appears on every service page and the blog index.

## 4. Search engine optimization — built in, not bolted on

| SEO element | Before | Now |
|---|---|---|
| Canonical URLs | Pointed at GoDaddy's domain (confused search engines) | Self-referencing — each page names itself |
| robots.txt | Invisible behind GoDaddy controls | At `yoursite.com/robots.txt`, allows all crawlers |
| Sitemap | Auto-generated by GoDaddy | Lists all 51 pages at `yoursite.com/sitemap.xml` |
| Structured data | None visible | Organization markup (name, address, phone, hours), FAQPage schema (12 Q&As across two pages), Article schema (all 39 posts) |
| Title & descriptions | Controlled by GoDaddy templates | One sentence per page, written for the searcher's intent |

When you swap the DNS record over, these signals become authoritative immediately.

## 5. Content migration — all 39 articles intact

- **39 blog articles** transferred verbatim from the GoDaddy export.
- Each article is a full page with heading hierarchy, lists, blockquotes, and paragraph structure.
- The blog index shows 1 featured post plus 38 cards — same navigation as before, cleaner layout.
- **43,687 words** of structured content ready for organic search to find.

## 6. Accessibility — works for everyone

Every route on the site (51 of them) passes basic accessibility checks:

- Keyboard-only users can tab through every link, form field, and button.
- Every form input has a clearly associated label.
- Skip-to-content link lets screen readers jump past the menu.
- Heading order is sequential (h1 → h2 → h3) — no levels skipped.
- All images have alt text. No visual content depends on color alone.

## 7. Analytics tracking — unchanged

Google Analytics ID `G-T6WJ6JJ992` loads exactly as before. You can verify this by checking the original source code on any live GoDaddy page — the tracking ID is identical. Page-level engagement tracking continues uninterrupted.

## 8. AI-agent readiness

The new site is structured to work well with modern AI search engines (ChatGPT, Perplexity, Google AI Overviews):

- Robots.txt allows all bots (`Allow: /`).
- Real page content (not JavaScript-obscured) is in the HTML response.
- Structured headings, list items, and answer capsules (question followed by direct answer).
- The FAQ sections on `/level-funded` and `/buy-sell-1` provide direct answers AI crawlers can cite.
- No `noindex` tags anywhere on money pages.

## 9. What's ready to deploy today

The site is built, tested, and running on Cloudflare's preview URL. To point `dwaiconsulting.com` to it requires a single DNS update on GoDaddy — swapping the CNAME or A record. There is no other code change needed.

One remaining task: set the `RESEND_API_KEY` secret so the contact form actually delivers emails. This takes one command:

```
cd /tmp/dwai && npx wrangler secret put RESEND_API_KEY --name dwaiconsulting-site
```

After that, every submitted form goes straight to your inbox.
